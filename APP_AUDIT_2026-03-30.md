## Supabase issues that still need fixing

### 1. `vehicles` schema drift

Live `vehicles` columns include:

- `range_efficiency_factor`
- `is_default`

App/backend expect:

- `range_efficiency`
- `is_primary`

Impact:

- The backend `vehicles.py` contract does not match the live Supabase schema.
- Direct writes using the old backend contract can fail.
- I worked around this in the app by storing vehicles in `profiles.preferences`, but the underlying table mismatch still needs to be corrected if you want the backend vehicles API to be trustworthy again.

Fix:

- Run `backend/migrations/009_align_live_schema.sql`

### 2. Storage bucket assumptions need validation

App expects:

- bucket `vehicle-photos`

Backend expects:

- bucket `checkin-images`

Impact:

- Vehicle photo uploads or check-in image uploads will fail if those buckets or policies are missing.

### 3. Backend service-role configuration still required

Account deletion depends on:

- `SUPABASE_SERVICE_ROLE_KEY` on the backend

Impact:

- Frontend delete-account flow may fail if backend is redeployed without that secret.
